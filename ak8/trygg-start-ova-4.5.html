A

Vad är en potens?

x · x = x²

Titta här

x · x kan skrivas som potensen x². x är bas och 2 är exponent.

3 · 3 = 3² = 9   x · x · x = x³   2x · x = 2x²

Skriv x² som x^2 eller x2 om du inte hittar tecknet ².

1Skriv som en potens.

a) x · x
b) a · a
c) b · b · b

2Beräkna.

a) 4²
b) 5²
c) 10²
d) 2³

3Förenkla.

a) 3x · x
b) 2a · 4a
c) x² + x²
d) 5y² − 2y²

4Sant eller falskt?

a) x · x = 2x
b) x² + x² = 2x²
c) 3² = 6

5Beräkna x² + 3x när x = 4.

Samla x²- och x-termer

x² för sig, x för sig.

Titta här

Multiplicera in. Samla sedan x²-termerna för sig och x-termerna för sig.

4x(x − 2) − 3x(x − 1) = 4x² − 8x − 3x² + 3x = x² − 5x
